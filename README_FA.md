# Reminder Android – نسخه ۲

پروژه اندرویدی مستقل با Kotlin و Jetpack Compose.

## امکانات پیاده‌سازی‌شده در این نسخه اولیه
- رابط فارسی و راست‌چین با تم روشن و تاریک
- صفحه خانه و بخش‌های یادآورها، اقساط، تولدها/متفرقه و انقضای محصولات
- ذخیره محلی اطلاعات روی گوشی با SharedPreferences و JSON؛ بدون حساب کاربری و بدون سرور
- ثبت چند سری برای یک محصول، با تعداد و تاریخ انقضای مستقل
- ثبت دستی محصول و اسکن بارکد اختیاری (در صورت پشتیبانی Google Play Services)
- هشدارهای تاریخ انقضا در ۷ روز قبل، یک روز قبل و روز انقضا
- زمان‌بندی یادآورها با AlarmManager و بازیابی برنامه‌ریزی‌ها پس از راه‌اندازی مجدد گوشی

## ساخت APK با Codemagic
1. محتویات این پوشه را در ریشه مخزن GitHub قرار دهید؛ خود فایل ZIP را داخل مخزن آپلود نکنید.
2. مخزن را در Codemagic انتخاب کنید.
3. Workflow با نام `android-apk` را اجرا کنید.
4. خروجی در بخش Artifacts با مسیر `app/build/outputs/apk/debug/` قرار می‌گیرد.

این پروژه در محیط فعلی با Android SDK کامپایل و تست نشده است؛ اولین Build در Codemagic باید بررسی شود. فایل خروجی Debug APK با کلید Debug خود Gradle امضا می‌شود.
